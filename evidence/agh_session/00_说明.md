## 四、一个必须如实说明的边界

本机 AGH 的 `local-dev` 档案里，**shell 能力被策略禁用**（`CAPABILITY_DENIED`），
且 stdio/HTTP 两种 MCP 传输分别受「可执行文件白名单」与「回环 HTTP 需显式策略 +
本机代理干扰」限制，因此 **EDA 命令（iverilog/vvp/yosys）不是由 AGH 直接敲出去的**，
而是由本项目的工具层调用，再由裁判判定。

这正是本项目的设计选择，也是要在答辩时讲清楚的一点：

> **判定标准必须与生成过程相互独立。** 让模型（或驱动模型的框架）去调用验证工具，
> 再由它自己报告「我通过了」，结论是不可复核的。本项目把 EDA 调用与判定放在
> 独立工具层，AGH 负责规划、生成与修复，两者通过 MCP 接口与文件解耦——
> 所以评委即使完全不装 AGH，只用 `python run.py` 也能复现每一个判定。

`05` 号文件就是这条设计的实证：AGH 生成 → 独立裁判复验 → 结论一致。
