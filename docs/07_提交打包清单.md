```
└── 08_截图/                      主页首屏 / 成绩单 / GitHub 仓库页
```

**不放进 ZIP 的东西**（以及原因）：

| 排除项 | 原因 |
|---|---|
| `tools/oss-cad-suite`（600 MB） | 超体积上限；README 给官方下载地址，评委自取 |
| `runs/` 全量中间产物（4.6 MB） | 只保留 `evidence/` 里已整理的关键流水 |
| `~/.agnes_key`、任何 `sk-` 密钥 | 绝不入包（脚本每次打包都会扫一遍并报错拦停） |
| `.git/`、`node_modules/`、`__pycache__/` | 无关内容 |

## 五、提交前最后三件事

1. **补信息**：把 `submit/team.json` 里的 `【待填：…】` 换成真实姓名 / 学校 /
   学院 / 专业 / 年级，重新跑一次 `python package_submission.py`。
2. **录视频**：按 `04_演示视频与路演脚本.md` 录 3–5 分钟，传到 B 站设为**公开**，
   用**无痕窗口**确认不登录也能播放；把链接填进 `submit/team.json` 的 `video_main`。
3. **上传页面前自查**：打开 https://verilog-loop-lab.app.workbuddy.host/
   与 GitHub 仓库，确认现行内容与你想要的一致（公开内容改动后需重新发布）。
